# Hola Mundo con Docker


# Raul Daniel Sanchez Sanchez | 2024-1755


## Ejecución

1. Abre PowerShell en la carpeta del proyecto.
2. Ejecuta:

```powershell
docker compose up --build
```

3. Abre en el navegador: http://localhost:5000

## Detener la aplicación

Presiona `Ctrl + C` y ejecuta:

```powershell
docker compose down
```
